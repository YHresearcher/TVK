# TVK — P0 hardening review (2026-11-18)

Status: **PROPOSED / NOT DEPLOYED**. No Supabase staging or production tests have been run.

## Changes
1. Restore functionality of cost-free `v_batches_for_sales` after `0019` set `security_invoker=true`, which conflicts with `0018` denying SALES direct SELECT on `stock_batches`. View remains explicitly limited to projected columns and no `unit_cost`. Confirm actual role/column leakage on staging.
2. Block INSERT/UPDATE/DELETE on `sales_document_lines` for non-DRAFT parent documents. This protects against mismatches with stock ledger and payables.
3. Validate VAT invoice input is non-empty, unique, confirmed, and from the specified partner. Existing active VAT line uniqueness remains enforced by DB index.
